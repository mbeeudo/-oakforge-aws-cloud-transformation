## 📌 About the Project

**OakForge Solutions** is a fictional growing technology and digital services company whose legacy IT environment is becoming increasingly difficult to manage, secure, and scale as the business expands.

I created OakForge as a realistic business case study to apply what I'm learning through AWS re/Start to an end-to-end AWS Cloud Transformation. Each project addresses a specific business or technical challenge while contributing to a larger modernization strategy.

As the Cloud Professional responsible for the transformation, my goal is to design and implement a:

- Secure
- Reliable
- Scalable
- Cost-conscious
- Highly observable

AWS environment while introducing serverless and AI-powered capabilities to improve OakForge's operations.

> **This is a learning project, not a production system. Architecture and implementation decisions are documented with production considerations in mind.**

---

# 🏢 The Business Problem

OakForge Solutions is experiencing:

- 💰 Unpredictable cloud costs
- 🛡️ Weak data protection and disaster recovery
- 📊 Limited application availability monitoring
- 🤖 Manual customer support processes
- 📦 Inefficient inventory management
- 🖼️ Large volumes of product/media images
- 🌍 Customers speaking different languages
- 🔐 Infrastructure that needs stronger security and isolation

Management has therefore approved an **AWS Cloud Transformation Program**.

---

# 🎯 Transformation Objectives

The transformation aims to help OakForge:

| Business Need | Cloud Solution |
|---|---|
| Control AWS spending | Cost intelligence & budget alerts |
| Protect business data | Automated backup & disaster recovery |
| Detect outages quickly | Website availability monitoring |
| Improve customer support | AI-powered inquiry management |
| Improve inventory decisions | AI demand forecasting |
| Build modern applications | Serverless customer application |
| Automate image analysis | AI image processing pipeline |
| Support international customers | Multilingual AI assistant |
| Secure production workloads | Three-tier AWS architecture |

---

# 🏗️ Transformation Roadmap

The transformation consists of **nine connected projects**.

### Phase 1 — Foundation

**01. Cloud Cost Intelligence & Budget Alerts**

Establish cost visibility, budgets, and proactive spending alerts.

**02. Automated Backup & Disaster Recovery**

Introduce automated data protection and recovery capabilities.

### Phase 2 — Operations

**03. Website Availability Monitoring**

Monitor application availability and notify the team when outages occur.

### Phase 3 — Application Development

**06. Serverless Customer Application**

Build a customer-facing application using managed and serverless AWS services.

### Phase 4 — AI & Automation

**04. AI Customer Inquiry Management**

Use generative AI to assist with customer inquiries.

**05. AI Inventory & Demand Forecasting**

Analyze sales data and generate inventory recommendations.

**07. AI Image Processing Pipeline**

Automatically analyze uploaded product images.

**08. Multilingual AI Assistant**

Use conversational AI and translation services to support international customers.

### Phase 5 — Secure Infrastructure

**09. Secure Three-Tier AWS Architecture**

Design and implement a secure, isolated production-style AWS network architecture.
